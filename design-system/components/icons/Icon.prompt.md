Use `Icon` for every glyph. aicoo Coordinator uses **lucide only** — no emoji, no icon font, no hand-drawn SVG.

```jsx
<Icon name="folder-kanban" size={16} />
<Icon name="message-square" size={20} color="hsl(var(--muted-foreground))" />
```

The product's working vocabulary: `layout-dashboard`, `folder-kanban`, `message-square`, `hash`, `book-open`, `boxes`, `calendar`, `chevron-right`, `chevrons-up-down`, `chevron-down`, `chevron-left`, `plus`, `search`, `settings`, `shield-check`, `user-circle`, `log-out`, `help-circle`, `languages`, `sun`, `moon`, `monitor`, `mail`, `mic-2`, `plug`, `users`, `grip-vertical`, `pen-square`, `archive`, `alert-circle`, `clock`, `clipboard-edit`, `plus-circle`, `file-plus`, `refresh-cw`, `milestone`, `loader-2`, `check`, `circle`, `x`.

Only vendor logos are raster/SVG assets (`assets/slack-logo.svg`, `assets/teams-logo.svg`, `assets/sembly-ai-logo.svg`).
